# Jogo-Donkey-Kong-do-Sert-o-Nordetino
Lua do Sertão é um jogo de plataforma arcade inspirado nos clássicos de escalada e resgate.  No sertão nordestino, o Coronel Caboré sequestra Maria e a leva para o alto de um morro. O jogador controla um vaqueiro que precisa subir pelas plataformas inclinadas, usar escadas, pular obstáculos e evitar os barris lançados pelo vilão.
