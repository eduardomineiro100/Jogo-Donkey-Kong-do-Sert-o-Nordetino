# Lua do Sertão - Jogo-Donkey-Kong-do-Sert-o-Nordetino
Lua do Sertão é um jogo de plataforma arcade inspirado nos clássicos de escalada e resgate.  No sertão nordestino, o Coronel Caboré sequestra Maria e a leva para o alto de um morro. O jogador controla um vaqueiro que precisa subir pelas plataformas inclinadas, usar escadas, pular obstáculos e evitar os barris lançados pelo vilão.

**Lua do Sertão** é um jogo arcade de plataforma inspirado nos clássicos de escalada e resgate, ambientado no sertão nordestino.

## História

O Coronel Caboré levou Maria para o alto do morro. Assuma o papel de um vaqueiro e suba pela caatinga para resgatá-la, desviando dos barris do vilão pelo caminho.

## Como jogar

Abra o arquivo `index.html` em um navegador moderno. Não é necessário instalar dependências nem iniciar um servidor.

| Tecla | Ação |
| --- | --- |
| `←` e `→` | Move o vaqueiro para os lados |
| `↑` | Sobe escadas |
| `Espaço` | Pula |

## Objetivo

Chegue ao topo do morro e alcance Maria. Você começa com três vidas; evite os barris e não caia das plataformas.

## Destaques

- Cenário em pixel art com pôr do sol, lua e mandacarus.
- Plataformas inclinadas e escadas para escalar.
- Barris que percorrem as plataformas como obstáculos.
- Pontuação, vidas e telas de vitória ou derrota.
- Funciona diretamente no navegador, sem bibliotecas externas para o jogo.
